# Learning: 文档必须与代码同步更新

**记录时间**：2026-03-22
**触发原因**：用户发现 PD.md/2K.md/project.md 与实际代码严重脱节——卡片系统重构(P0-P4)、柏拉图模块、三阶段触发逻辑均已在代码中实现，但文档仍是旧版本。

## 错误行为
- 完成功能后没有同步更新需求文档和架构文档
- 在对话中口头承诺"后续更新"但没有执行

## 正确行为
每完成一个功能模块，**必须在同一轮操作中**更新：
- `PD.md` 对应功能的验收标准
- `2K.md` 对应的架构描述
- `project.md` 变更记录 + 里程碑状态

## 记录到 CLAUDE.md
已写入项目级 CLAUDE.md 的"文档同步规则"章节。

## 关键提醒
用户使用 Vibe Coding 方法论，步骤 7 明确要求"大改动时同步更新文档"。
这不是可选项，是开发规范的一部分。
